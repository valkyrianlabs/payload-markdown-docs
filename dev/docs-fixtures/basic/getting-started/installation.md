# Installation

:::steps {variant="cards" layout="stack" numbered stepTheme="glass"}

### Configure the database

Set `DATABASE_URL` for the dev Payload app.

### Generate keys

Run the dev keypair script and restart the dev server so it can read the public key.

### Seed docs infrastructure

Create the `Plugins` docs group and `Payload Markdown Docs` docs set.

:::
